# Ответы на вопросы

## Подключеение Orbbec Astra, ультразвуковых датчиков и GPS к Raspberry PI 5

- Orbbec Astra: USB для данных и питания. Для классической Astra нужен: совместимый OpenNI/Astra SDK и проверка поддержки выбранного Linux ARM64; SDK, который выбирается по конкретной модели камеры. Информация по самой камере [Orbbec](https://www.orbbec.com/products/structured-light-camera/astra-series/) и по SDK [OpenNI SDK](https://www.orbbec.com/developers/openni-sdk/).

- Ультразвуковой модуль с TRIG/ECHO: GPIO для запуска и измерения длительности импульса. Если ECHO выдаёт 5 В, нужен делитель или преобразователь уровня до 3,3 В. Несколько датчиков запускать по очереди, чтобы исключить взаимные помехи. Для точного измерения удобно использовать отдельный микроконтроллер и передавать расстояния по UART или I2C.

- GPS: USB-приёмник либо UART с согласованными уровнями. У UART-модуля TX подключается к RX Pi, RX — к TX, плюс общая земля. Для UART нужно отключить консоль на выбранном порту. Скорость и протокол берутся из паспорта модуля.

- GPIO Raspberry Pi работают с уровнями 3,3 В. Распиновку и ограничения можно посмотреть тут:
[документация Raspberry Pi](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#gpio-and-the-40-pin-header).

## Организация питания от одного аккумулятора

- Питание от аккумулятора в роботе идёт через систему управления аккумулятором, предохранитель/систему предохранителей, которая в свою очередь соединена с кнопкой аварийного выключения. От предохранителя питание идёт на драйверы моторов, модуль управления роботом, например Raspberry PI и на прочие компоненты.

## Проверка работоспособности датчиков без ROS

- Камера: в терминале linux - 'lsusb', если камера отображается - проверить вывод видеоряд с помощью встроенных инструментов камеры, например в браузере, если камера работает по протоколу http.

- GPS: прочитать последовательный порт через терминал или `gpsd/cgps`. Проверить NMEA, валидный fix и координаты на открытом воздухе.

- Ультразвук: отдельный скрипт/прошивка TRIG/ECHO, расчёт расстояния по формуле `d = c * dt / 2`, или сравнение с рулеткой. 

- Энкодеры: провернуть колесо с датчиком на один оборот и сверить показания.
